## 📱 About The App
AlagaBrowser குறைந்த அளவிலான மெமரி பயன்பாட்டுடன், எளிய மற்றும் நேரடியான உலாவல் அனுபவத்தை வழங்குகிறது. எந்தவிதக் கூடுதல் விளம்பரத் தடங்கல்களோ சிக்கலான மெனுக்களோ இன்றி பயனர் விரும்பும் இணையதளங்களை விரைவாக லோட் செய்ய இது வடிவமைக்கப்பட்டுள்ளது.

---

## ✨ Features
* 🚀 **Fast & Smooth Browsing:** குறைவான லோடிங் நேரத்துடன் இணையதளங்களை இயக்கும் சிறப்பம்சம்.
* 🌐 **Full Web Support:** நவீன வலைத்தளங்களை ஆதரிக்க JavaScript மற்றும் DOM Storage வசதிகள் இயக்கப்பட்டுள்ளன.
* 🔙 **Smart Back Navigation:** தற்செயலாக ஆப் மூடப்படாமல், முந்தைய இணையப் பக்கங்களுக்குச் செல்ல உதவும் Back Navigation ஆதரவு.
* 📱 **Minimal UI:** கவனச்சிதறல் இல்லாத முழுமையான உலாவல் திரை அனுபவம்.

## 🚀 How To Use
1. [Download the APK](https://github.com/AlagarSadjac/alaga-browser-android/releases/latest) ஃபைலை டவுன்லோட் செய்து இன்ஸ்டால் செய்யவும்.
2. ஆப்பைத் திறந்தவுடன் முகப்புப் பக்கம் (Home Page) உடனடியாகத் திரையிடப்படும்.
3. விரும்பிய இணைப்புகளைத் தட்டிப் பிரவுஸ் செய்யவும்; முந்தைய பக்கத்திற்குச் செல்ல மொபைலின் Back பட்டனைப் பயன்படுத்தவும்.

## 🎯 Purpose
ஆண்ட்ராய்டு இயங்குதளத்தில் WebView-ஐ முழுமையாகப் பயன்படுத்தி, பயனர் சாதனத்தின் பேட்டரி மற்றும் டேட்டாவை வீணடிக்காத ஒரு எளிய, எடை குறைந்த பிரவுசரை உருவாக்குவதே இதன் நோக்கமாகும்.
