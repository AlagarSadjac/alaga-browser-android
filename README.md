## 📱 About The App
AlagaBrowser offers a direct, distraction-free browsing experience with minimal memory consumption. It is engineered to load web pages instantly without heavy background processes, optimizing performance, battery life, and data usage.

---

## ✨ Features
* 🚀 **Fast & Smooth Browsing:** High-speed rendering with optimized page load performance.
* 🌐 **Full Web Support:** Enabled JavaScript and DOM Storage for modern interactive web applications.
* 🔙 **Smart Back Navigation:** Integrated navigation history stack preventing accidental app closure when going back.
* 📱 **Minimal UI:** Clean and focused interface for unobstructed web viewing.

---

## 🛠️ Built With
* **Language:** Java
* **IDE:** Android Studio
* **Layouts:** XML Layouts & ConstraintLayout
* **Core Components:** WebView, WebSettings, WebViewClient
* **Version Control:** Git & GitHub

## 🚀 How To Use
1. Download and install the APK using the download button above.
2. Launch the app to display the home page instantly.
3. Browse web pages directly; use your device's Back button to return to previous pages seamlessly.
  
---

## 🎯 Purpose
The objective of this project is to implement a robust, lightweight Android browser client leveraging the Android WebView API, emphasizing minimal resource consumption and clean application architecture.
